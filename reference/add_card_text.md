# Helper to add text to each card plot in a list

`add_card_text()` is a helper function used internally by
[`plot_cards()`](https://elipousson.github.io/papersize/reference/plot_cards.md).

## Usage

``` r
add_card_text(
  plots,
  card = NULL,
  text = NULL,
  color = "white",
  size = 5,
  family = NULL,
  nudge_x = 0,
  nudge_y = 0.5
)
```
