# Helper to add a number to each card plot in a list

`add_card_number()` is a helper function used internally by
[`plot_cards()`](https://elipousson.github.io/papersize/reference/plot_cards.md)
to apply a number to each card in a list of plots.

## Usage

``` r
add_card_number(
  plots,
  card = NULL,
  n = 1,
  color = "white",
  size = 5,
  family = NULL,
  sequence = TRUE
)
```
